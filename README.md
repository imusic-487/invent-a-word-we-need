Entry for the [Invent a Word We Need](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0) bounty on make.fun.

`main.py` writes one invented English word with a one-line definition to `/output/entry.txt`:

> Fridgehope (n.): the hope that something delicious has appeared in the fridge since the last time you looked.

Run it with:

```sh
python3 main.py
```
